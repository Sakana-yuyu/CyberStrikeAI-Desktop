# 桌面聊天中的排队、引导与问答

主聊天区在同一会话已有 Agent 任务运行时仍可输入新消息。点击“加入队列”或按 Enter 后，消息进入该会话的待发队列；当前任务结束后，页面会按顺序发送队首消息。横幅显示排队数量和队首内容，可移除队首消息。队列保存在本机浏览器的 `localStorage`，刷新页面后仍可恢复；清除浏览器数据或更换设备后不会同步。

任务运行期间，纯文本队首消息可点击横幅中的“引导 Agent”。服务端将方向交给当前 Eino TurnLoop，在当前步骤完成后作为下一轮输入处理；它不会取消正在执行的工具或推理。带附件的消息只能在任务结束后按队列发送。若任务在点击时已经结束，服务端返回冲突，队列消息仍保留。

Agent 遇到确实需要用户决定的关键问题时，可调用 `ask_user`。聊天区弹出问题及建议选项，用户可点选或自行输入；提交后同一任务继续。问题属于当前运行任务的内存状态，刷新页面会通过 `GET /api/chat/question?conversationId=...` 恢复待回答弹窗；任务取消或进程重启后，未回答问题随任务结束而失效。问答不代替 HITL 工具审批。

相关接口：

| 方法和路径 | 用途 |
| --- | --- |
| `POST /api/agent-loop/guide` | 提交 `{conversationId,message}`，向运行中任务加入不抢占的引导。 |
| `GET /api/chat/question?conversationId=...` | 查询当前会话的待回答问题。 |
| `POST /api/chat/question/answer` | 提交 `{conversationId,questionId,answer}`。 |

以上接口沿用会话访问权限检查。`ask_user` 的问题和答案通过任务 SSE 事件同步到当前聊天页与刷新后的任务补流；工具审批仍由 HITL 独立处理。
