## Lessons
### L-1 本地已有修改先快照隔离（source: Round 1）
备用 Git 索引记录源码，不改变用户暂存区；只合入公开上游到隔离分支。翻译文件主要为缩进差异，应先规范化合并，避免整文件手工覆盖。

### L-2 页面事件必须在状态提交后派发（source: Round 1）
订阅者与派发者使用同一 EventTarget；文件树应复用聊天项目选择器的归属规则，不能把无项目历史会话回退到新任务的活动项目。新建动作先提交项目再通知所有订阅者。
